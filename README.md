#BRUME
## 📖 Introduction

**Product Configurator** is an interactive web application built as part of a 5-day development simulation. 

The goal is to provide a seamless, real-time customization experience where users can build their ideal product *(artisanal coffee or cosmetics)*, watch the price update instantly, and save their final configuration. 

This project focuses on:
* **Vanilla JavaScript:** Dynamic DOM manipulation.
* **Professional Workflow:** Clean GitFlow practices and structured project management.
* **UX/UI Design:** Fully responsive layouts for an optimal user experience on all devices.
## 🛠️ Built With
- HTML5
- TailwindCss (Flexbox / CSS Grid)
- Vanilla JavaScript (ES6)
